# MASTER_SETUP.md — Единый конфиг мастера

Все настройки бота для мастера сосредоточены в двух файлах:
- **`.env`** — секретные данные (токен бота, Telegram ID)
- **`config.json`** — публичные настройки (услуги, тексты, расписание)

---

## Быстрый старт

```bash
python3 setup_master.py
```

Скрипт задаст все вопросы и автоматически создаст оба файла.

## Полная структура .env

```ini
# Обязательные поля
BOT_TOKEN=1234567890:ABCdef...         # Токен от @BotFather
ADMIN_IDS=123456789                    # Ваш Telegram ID (найти: @userinfobot)

# База данных
DB_PATH=data/manicure_bot.db

# Временная зона
TIMEZONE=Europe/Moscow                 # Для напоминаний в правильное время

# Напоминания
REMINDER_HOURS_BEFORE=24               # За сколько часов до визита

# Ограничения
MAX_APPOINTMENTS_PER_USER=1            # Максимум записей у одного клиента

# Опциональные
REQUIRED_CHANNEL=@your_channel        # Канал, на который нужно подписаться
PORTFOLIO_URL=https://instagram.com/... # Ссылка на портфолио (WebApp)
PHONE=+7 999 123-45-67
INSTAGRAM=@master_manicure
ADDRESS=Москва, ул. Примерная, д. 1
LOG_LEVEL=INFO
```

## Что НЕ нужно перезапускать бот после изменения

Через **админ-панель бота** можно менять без перезапуска:
- ✅ Текст приветствия
- ✅ Фото приветствия
- ✅ Услуги и цены (добавить/изменить/удалить)
- ✅ Рабочие часы
- ✅ Интервал между записями
- ✅ Время напоминания

Изменения применяются немедленно и сохраняются в `config.json`.

---

## Что требует перезапуска

- Изменение `BOT_TOKEN` или `ADMIN_IDS` (в `.env`)
- Изменение `TIMEZONE` (в `.env`)
- Изменение `DB_PATH` (в `.env`)
- Обновление версии бота (новый код)
