# CUSTOMIZATION.md — Руководство по кастомизации

## Что менять под каждого мастера

### ✅ Через интерфейс бота (без перезапуска)

Войдите в бот → `/admin` → **⚙️ Настройки**:

| Кнопка | Что меняет |
|--------|-----------|
| ✏️ Текст приветствия | Сообщение при /start (поддерживает {name}, HTML) |
| 📸 Фото приветствия | URL фото-баннера |
| 💅 Услуги и цены | Добавить/изменить/удалить услуги |
| 🕐 Рабочие часы | Временные слоты (09:00-18:00 или список) |
| ⏱ Интервал записи | Минуты между слотами (30, 60, 90...) |
| 🔔 Время напоминания | За сколько часов до визита (1-72) |

---

## Как добавить новые услуги

### Способ 1: Через бота (рекомендуется)
1. `/admin` → **⚙️ Настройки** → **💅 Услуги и цены**
2. Нажмите **➕ Добавить услугу**
3. Введите: название → цену → длительность

### Способ 2: Через config.json
```json
"services": {
    "Маникюр": {"price": 1500, "duration": 60},
    "Педикюр": {"price": 2000, "duration": 90},
    "Гель-лак": {"price": 500, "duration": 30},
    "Наращивание": {"price": 3500, "duration": 180},
    "Дизайн (1 ноготь)": {"price": 100, "duration": 5}
}
```
После редактирования файла перезапустите бота:
```bash
systemctl restart manicure_bot
```

## Как изменить расписание

### Установить рабочие часы через бота
1. `/admin` → **⚙️ Настройки** → **🕐 Рабочие часы**
2. Введите в формате `09:00-18:00` или список: `10:00,12:00,14:00,16:00`

### Управление конкретными днями
1. `/admin` → **🗓 Расписание** → **📅 Просмотр дней**
2. Выберите дату для добавления/удаления слотов

### Открыть неделю сразу
1. `/admin` → **🗓 Расписание** → **📅 Открыть неделю**
2. Бот откроет ближайшие 5 рабочих дней

### Шаблоны расписания
1. `/admin` → **🗓 Расписание** → (в меню есть кнопка шаблонов)
2. Сохраните шаблон → Применяйте к любой дате одним нажатием

## Как настроить напоминания

### Через бота
1. `/admin` → **⚙️ Настройки** → **🔔 Время напоминания**
2. Введите количество часов (1-72)

### Что получает клиент
Бот отправляет напоминания автоматически:
- За `reminder_hours_before` часов (настраивается)
- За 2 часа
- За 1 час

В напоминании есть кнопки:
- **✅ Приду** — подтверждение
- **❌ Отменить** — отмена прямо из напоминания

## Как сделать рассылку

1. `/admin` → **📢 Рассылка**
2. Введите текст сообщения (поддерживает HTML-форматирование)
3. Просмотрите предпросмотр
4. Нажмите **✅ Отправить всем**

Рассылка отправляется всем пользователям, которые когда-либо писали боту.

**HTML-теги для красивого текста:**
```html
<b>жирный</b>
<i>курсив</i>
<u>подчёркнутый</u>
<code>моноширинный</code>
🌸 Можно использовать эмодзи
```

## Описание разделов админ-панели

### 📅 Сегодня
Список записей на сегодня. Для каждой записи кнопки:
- **✅ Пришла** — отмечает визит и отправляет благодарность клиенту
- **❌ Отменить** — отменяет запись с уведомлением клиента

### 📋 Все записи
Просмотр всех записей с фильтрами:
- Сегодня / За неделю / Активные / Все
- Статистика по месяцам (пиковые часы, популярные дни)

### 🗓 Расписание
Управление рабочими днями и слотами:
- Добавить/удалить конкретные слоты
- Открыть/закрыть день
- Открыть сразу неделю
- Шаблоны расписания
- Массовая отмена всех записей на дату

### 👥 Клиенты
- **Найти клиента** — поиск по имени/телефону
- **История клиента** — все записи конкретного клиента
- **Написать клиенту** — личное сообщение любому клиенту

### ⚙️ Настройки
Полное управление ботом без перезапуска:
- Тексты (приветствие, фото)
- Услуги и цены
- Рабочие часы и интервал
- Напоминания

### 🚫 Чёрный список
- Заблокировать/разблокировать пользователя по ID
- Просмотр текущего списка

### 📊 Статистика
- Всего/активных/отменённых записей
- Записи сегодня и за неделю
- **Выручка** за сегодня/неделю/месяц

### 📢 Рассылка
Массовая отправка сообщений всем пользователям бота.

### ⬇️ Экспорт CSV
Скачать все записи в CSV-таблицу для обработки в Excel.

## Настройка текстов

### Переменные в текстах
- `{name}` — имя клиента (в приветствии и благодарности)
- HTML-теги поддерживаются везде

### Где хранятся тексты
Файл `config.json`:
```json
{
  "bot": {
    "welcome": "Привет, {name}! 🌸\n\nЯ — Анастасия...",
    "help_text": "ℹ️ <b>Справка</b>..."
  },
  "master": {
    "after_visit_text": "Спасибо, {name}! 🌷\n\n...",
    "welcome_text": "Текст приветствия..."
  },
  "prices_title": "💅 <b>Прайс-лист</b>...",
  "prices_footer": "...",
  "contacts_title": "📞 <b>Связаться</b>..."
}
```

## Листы ожидания

Если клиент выбрал дату без свободных слотов, ему предлагается встать в лист ожидания.

Когда другой клиент отменяет запись — всем в листе ожидания приходит уведомление с кнопкой **✅ Забронировать!**

Настройка: работает автоматически, ничего делать не нужно.

## Добавление фото к приветствию

1. Загрузите фото на любой хостинг изображений (Imgur, Postimages и т.д.)
2. Скопируйте прямую ссылку на изображение (должна заканчиваться на .jpg, .png и т.д.)
3. В боте: `/admin` → **⚙️ Настройки** → **📸 Фото приветствия**
4. Вставьте ссылку

Или добавьте в `.env`:
```ini
WELCOME_PHOTO_URL=https://example.com/photo.jpg
```

## Требование подписки на канал

Для принудительной подписки клиентов на ваш Telegram-канал:

```ini
# .env
REQUIRED_CHANNEL=@your_channel_name
```

Клиент не сможет записаться, пока не подпишется. После подписки — автоматически пропускается.

## Портфолио (WebApp)

Для кнопки "Портфолио" в главном меню:

```ini
# .env
PORTFOLIO_URL=https://instagram.com/your_profile
# или
PORTFOLIO_URL=https://your-website.com/portfolio
```

Кнопка появится в главном меню, откроет ссылку через WebApp.
