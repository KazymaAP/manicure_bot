# 💅 Manicure Bot v4 — Telegram-бот для онлайн-записи

Telegram-бот для записи клиентов к мастеру маникюра (или любой другой услуги).
Легко настраивается под любого мастера без изменения кода.

## ✅ Возможности

- 📅 Онлайн-запись через интерактивный календарь
- ⏰ Автоматические напоминания клиентам (настраиваемый интервал)
- 🔑 Панель администратора: управление расписанием, записями, статистика
- 📢 Опциональная проверка подписки на канал
- 💅 Кнопка Портфолио (Instagram / Telegram / сайт)
- 📊 Статистика записей
- 🐳 Docker-ready

## 🚀 Быстрый старт

### 1. Скопируй .env.example в .env и заполни:
    cp .env.example .env

Обязательные поля в .env:
    BOT_TOKEN=<токен от @BotFather>
    ADMIN_IDS=<твой Telegram ID, например: 123456789>

### 2. Установи зависимости:
    pip install -r requirements.txt

### 3. Запусти бота:
    python main.py

### 4. (Опционально) Запуск через Docker:
    docker-compose up -d

## ⚙️ Настройка для мастера

Все параметры конфигурируются через **два файла**:

### Файл 1: `.env` — секреты и технические параметры
| Переменная | Описание | Пример |
|---|---|---|
| BOT_TOKEN | Токен бота от @BotFather | 1234567890:AAF... |
| ADMIN_IDS | Telegram ID администратора | 123456789 |
| PORTFOLIO_URL | Ссылка на портфолио (пусто = скрыть кнопку) | https://instagram.com/me |
| REQUIRED_CHANNEL | Канал для обязательной подписки (пусто = выкл) | @my_channel |
| REMINDER_HOURS_BEFORE | За сколько часов напоминать (по умолч. 24) | 24 |
| MAX_APPOINTMENTS_PER_USER | Макс. записей на клиента (по умолч. 1) | 1 |

### Файл 2: `config.json` — тексты и внешний вид
| Поле | Описание |
|---|---|
| bot.service_name | Название услуги ("маникюр", "педикюр", "брови") |
| bot.master_name | Имя мастера в текстах |
| messages.welcome | Приветственное сообщение |
| buttons.book | Текст кнопки записи |
| schedule.days_ahead | Горизонт доступных дат (дней) |
| schedule.default_time_slots | Слоты по умолчанию при открытии дня |

## 📋 Команды бота

| Команда | Описание |
|---|---|
| /start | Начать работу с ботом |
| /help | Справка для пользователя |
| /admin | Войти в панель администратора |

## 🛠 Технический стек

- **Python 3.10+**
- **aiogram 3.13** — Telegram Bot framework
- **SQLite + WAL** — база данных (файл, не требует сервера)
- **APScheduler** — напоминания
- **Pydantic v2** — валидация конфигурации
- **Docker** — опциональная контейнеризация

## 🔒 Безопасность

- Токены и секреты — только в `.env`
- `.env` исключён из репозитория через `.gitignore`
- Атомарное бронирование слотов (нет двойных записей)
- Проверка прав администратора на всех admin-эндпоинтах
